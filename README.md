### 📖 About This Repository

This repository is my personal study log, hands-on lab configuration archive, and network topology collection (`.pkt`) for the **Cisco Certified Network Associate (CCNA 200-301)** exam — built while following **[Jeremy's IT Lab CCNA Course & Labs](https://youtube.com/playlist?list=PLxbwE86jKRgMQ4HTuaJ7yQgA2BoNwY9ct)** on YouTube.

Everything here — from subnetting drills to VLAN trunking labs to OSPF configs — is documented as I learn it, so this repo doubles as both a **study journal** and a **reusable command reference**.

## 🛠️ Quick CLI Reference

| 🎯 Purpose | 💻 Cisco IOS Command |
|---|---|
| Enter Privileged Mode | `enable` |
| Enter Global Config | `configure terminal` |
| Set Hostname | `hostname <NAME>` |
| Set Encrypted Password | `enable secret <PASSWORD>` |
| Create VLAN | `vlan <ID>` → `name <NAME>` |
| Configure Trunk Port | `switchport mode trunk` |
| Configure SVI | `interface vlan <ID>` → `ip address <IP> <MASK>` |
| Default Static Route | `ip route 0.0.0.0 0.0.0.0 <NEXT_HOP_IP>` |
| OSPF Setup | `router ospf <ID>` → `network <NET> <WILDCARD> area <AREA>` |
| Check Interfaces | `show ip interface brief` |
| Check Routing Table | `show ip route` |
| Save Configuration | `copy running-config startup-config` |
